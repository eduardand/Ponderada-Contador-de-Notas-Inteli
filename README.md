# 📚 Contador de Notas Escolares

Este projeto é um programa simples desenvolvido em **JavaScript** que auxilia no cálculo da **média das notas** dos alunos e determina se foram **aprovados** ou **reprovados**.

## 🛠️ Tecnologias Utilizadas

- **JavaScript**: Linguagem de programação utilizada para a lógica do cálculo da média.

## 🚀 Funcionalidades

- **Cálculo Automático**: O sistema calcula a média das notas.
- **Classificação do Aluno**: Indica se o aluno está **aprovado** ou **reprovado**.

## 📝 Aprendizados

- **Uso de Variáveis**: Armazenar notas e calcular médias.
- **Estruturas Condicionais**: Uso de `if` e `else` para determinar a aprovação ou reprovação.
